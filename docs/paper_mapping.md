## Reproducing one claim

```bash
# all checks
rst-audit checks

# one figure
rst-audit figures        # redraws all five

# inspect a table
python -c "import pandas as pd; print(pd.read_csv('results/tables/table_window_comparison.csv').to_string())"

# recompute the case table from the raw panel (needs CITES_DB)
CITES_DB=data/cites.duckdb rst-audit audit
```

The check contract is the fastest route from a sentence in the manuscript to a
machine-verifiable quantity: look up the claim in the table above, read the
check key in `results/checks/checks.csv`, and compare `expected` with
`observed`.

## Notes on naming

- `figA0` is the manuscript's Figure 1; `figA2` is Figure 2; `figA4` is
  Figure 3; `figA3` is Figure 4; `figA5` is Figure 5. The original analysis
  order (A0, A2, A3, A4, A5) is preserved in filenames for traceability.
- `y_B` is the one-year label; `y_B3` is the three-year label.
- `pooled_top50` pools all five test years before taking the top 50;
  `per_year_top10` takes 10 per year (50 total); `unfiltered_top50` drops the
  candidate-universe filter.
- `confirmed_multi_base` = multi-year record support and record-ratio
  condition satisfied (verified); `confirmed_single_base` = one support year
  (watchlist).
